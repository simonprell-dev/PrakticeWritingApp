Krakel&Krone
Die Buchstaben machen sich schön … Die Fische putzen ihre Flossen … Zork poliert sein Raumschiff … Riese Rumpel sucht seine Krone … Die Stifte werden gespitzt … Die Seifenblasen werden aufgepustet …
Es geht nicht weiter? Dann bitte die Seite neu laden (Strg + F5).

Beim Entwickeln: Die Datei index.html kann man nicht direkt öffnen (auch nicht über eine Vorschau in VS Code). Im Terminal npm run dev eingeben und dann http://localhost:5173 in Chrome oder Edge öffnen.
